03

What Does “Next Small Thing” Mean?

Don't try to understand the entire topic at once.

💡

The Next Small Thing

It means the smallest piece of the topic that you need to understand right now — not the whole topic.

1
Where am I?

What part of the topic am I currently studying?

2
What don't I understand?

Identify one specific point of confusion.

3
What is the smallest question?

Find one small question you can answer next.

04

Example: Learning JavaScript

Break a complicated concept into small questions.

function memoize(fn) {
    const cache = {};

    return function(n) {
        if (cache[n]) return cache[n];

        cache[n] = fn(n);
        return cache[n];
    };
}
01

What does fn represent?

02

Why is cache an object?

03

What does return function(n) mean?

04

What happens when the returned function is called?

05

What does cache[n] do?

Don't Argue With Your Mind

Acknowledge the thought and return to your task.

🧠
YOUR MIND SAYS

“Maybe I should check that Excel problem first.”

↓
🎯
YOUR RESPONSE

“Not now. Write it down. Back to JavaScript.”

Then:
  • Write “Excel – check later.”
  • Return to your current topic.
  • Continue from the exact point where you stopped.
↩

Your Mental Reset Button

When your attention repeatedly escapes, don't criticize yourself.

“BACK TO THE TASK.”

Then identify your next physical action:

Read this paragraph. Trace this function. Understand this variable. Solve this one example.
07

Simple Deep-Focus Routine

Use this every time you study an important topic.

01

Choose One Topic

Decide exactly what you are going to study.

02

Set a Short Time

Start with 20 minutes of focused learning.

03

Use the Autosuggestion

“One topic. One question. One step at a time.”

04

Park Distractions

Write unrelated thoughts down and return later.

05

Find the Next Small Thing

Ask: “What is the smallest thing I need to understand?”

06

Return When You Wander

Every return is another repetition of your focus skill.

REMEMBER

Focus doesn't mean
never getting distracted.

Focus means noticing that your mind has wandered and calmly bringing it back.

One topic. One question. One step. One return at a time.
